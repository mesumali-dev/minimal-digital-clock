> A minimalist, responsive real-time digital clock built with TypeScript and CSS3, supporting 12/24-hour time formats and ambient typography transitions.

---

## ⏱ Features

- **Precision Seconds Rendering:** Real-time DOM clock synchronization via requestAnimationFrame/intervals.
- **Format Toggle:** Seamless switching between 12-Hour AM/PM and 24-Hour Military time.
- **Type-Safe Codebase:** Pure TypeScript logic with zero external runtime dependencies.

---

## How to Run

```bash
git clone https://github.com/mesumali-dev/minimal-digital-clock.git
cd minimal-digital-clock
# Open index.html in any browser
```
